Install uvicorn into this venv (once)
.\venv\Scripts\python.exe -m pip install "uvicorn[standard]"

Start backend (always works even if uvicorn command is not on PATH)
.\venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload

If you want all dependencies first, run:
.\venv\Scripts\python.exe -m pip install -r requirements.txt

Then run backend with:
.\venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
